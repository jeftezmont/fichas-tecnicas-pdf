# Compartir con otras IA

## Si admite importar habilidades

Prepara una copia independiente con esta estructura y conserva las rutas relativas:

```text
fichas-tecnicas-pdf/
  SKILL.md
  assets/antares-nova/azul.svg
  assets/antares-nova/blanco.svg
  assets/antares-nova/negro.svg
  references/compartir-con-otras-ia.md
```

Usa la opción de importación de la IA que recibirá la copia y su formato admitido. No metas el PDF de prueba, datos de clientes, historiales, credenciales ni archivos exclusivos de ChatGPT. Empaqueta como ZIP si el usuario lo pide.

## Si no admite importar habilidades

Copia el contenido de SKILL.md como instrucciones del chat o proyecto. Adjunta los tres logos por separado o déjalos como recursos del proyecto. Una instrucción inicial útil:

> Usa estas instrucciones como mi flujo para fichas técnicas Antares Nova. Primero busca el PDF existente del modelo exacto. Si no lo encuentras, crea la ficha corporativa con los logos adjuntos y las páginas que hagan falta.

Si la herramienta no admite SVG, se pueden convertir los logos a PNG transparentes para ese uso; conserva los SVG originales. La búsqueda web, la importación y la exportación a PDF dependen de la plataforma. Si no puede navegar, pásale el enlace, el texto o los archivos de origen; si no puede exportar a PDF, pídele un documento editable o HTML imprimible.
